notice and permission notice must accompany the copies shipped with Perch; this file is that
accompanying notice for the components in this directory.

Provenance
----------
- page-flip 2.0.7 — npm package `page-flip`, from github.com/Nodlik/StPageFlip (installed with
  `bun add page-flip`; resolved to 2.0.7, the current published release). Imported in
  BookFlip.tsx as `import { PageFlip, SizeType } from 'page-flip'`. It supplies only the
  page-turn behaviour; the pages it turns are Perch's own `.book-page` elements, and none of the
  library's markup, styles or assets are copied into Perch.
- @types/page-flip 2.0.4 — npm package `@types/page-flip` (DefinitelyTyped), installed with
  `bun add -d @types/page-flip`. Type declarations only; no runtime code.
- The page-turn option set and the prev/next control pattern (click an edge, drag, or the
  controls) follow the 2d-book example in HaichaoLihc/create-photo-flipbook-ui, an MIT-licensed
  reference the project chose as its behavioural model. Its page-flip options and control wiring
  are the reference; no code, assets or styling from that repository were copied.
