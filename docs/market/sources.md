# Sources: Every Product We Have Referenced

**Compiled 2026-09-06.** One place to click through everything named in
[`competitors.md`](competitors.md), [`landscape.md`](landscape.md) and [`deck-scan.md`](deck-scan.md), so that nobody
re-runs the search and so a judge's "have you looked at X" can be answered on the spot.

**How to read the confidence column.** The rubric is not helped by a link we have not opened, and rule 3 on this branch
forbids describing a feature nobody saw.

| Mark          | Means                                                                                  |
| ------------- | ---------------------------------------------------------------------------------------- |
| **read**      | The page was fetched and its text read. Quotes from these are exact                     |
| **listed**    | The URL came back as a search result and matches the product, but nobody opened it      |
| **no URL**    | The product was named in a round-up article. **We do not have its address** and have not invented one |
