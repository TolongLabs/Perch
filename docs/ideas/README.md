# Ideas

**Worth 3% directly** (Breadth Of Exploration), and it is where everything else starts.

> "Several distinct ideas generated and compared before choosing, with rationale." — the rubric, 3/3 band

One file per idea. Copy `_template.md`, number it, name it after the idea. Numbers just keep them in order; they do not
rank anything.

## What "Done" Looks Like

- **At least five genuinely different ideas**, not five versions of one. Different user, different moment of use,
  different mechanism - not a different feature list
- Each one written down **even if it is obviously bad**. A bad idea we can point at is evidence we explored. A bad idea
  we deleted is nothing
- The one we pick has a written reason for being picked, in `../decisions/iteration-log.md`

## Do Not

- **Do not delete an idea.** Ever. Dropped ones move to `../decisions/dropped.md` with a reason
- Do not polish an idea before writing it down. Rough is fine. Missing is not
