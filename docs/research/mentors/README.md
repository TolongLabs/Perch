# Mentors

**Worth 7%** (Mentor Consultation And Feedback Integration).

> "Feedback from mentor(s) is clearly documented and has been meaningfully incorporated into the concept." — the rubric,
> 6-7/7 band
>
> A mentor was consulted but no specific feedback is shown: **2-3 out of 7.**

**A session with no write-up scores the same as no session at all.** Write it up the same day, while you still remember
what was actually said rather than what you wish had been said.

## How Booking Works

| Rule            | Detail                                                                                 |
| --------------- | ---------------------------------------------------------------------------------------- |
| **When**        | 31 Aug - 13 Sept                                                                        |
| **Booking**     | Mentors post their own slots in a shared spreadsheet. First come, first served          |
| **Length**      | Up to 25 minutes                                                                        |
| **Platform**    | Discord, per the Kick-Off Day briefing. Watch the channel in case that changes          |
| **Daily limit** | Two per day per team. No cap on the total                                               |
| **Choosing**    | Each mentor lists a domain - AI, web, mobile, UX, pitching. Pick one who matches the question you actually have |

**Good slots go fast.** The mentor list, with credentials, is in `../brief.md`.

**Mentors will not design the solution or write code.** They ask questions and challenge the thinking. Bring a specific
question, not "what do you think of our idea".

## What "Done" Looks Like

- **More than one session**, with more than one mentor
- Each write-up quotes **what they actually said**, not a paraphrase of the gist
- Each write-up says **what we changed because of it** - and if we changed nothing, why not. A reasoned disagreement is
  still integration; silence is not
- The change also appears as a row in `../decisions/iteration-log.md`
