# Market

Feeds **Creativity And Novelty, 15%** - Originality (7%) and Differentiation From Existing Solutions (3%).

> "Judges will have seen a lot of to-do apps and trip planners. Give them a fresh angle, a feature or two that stands
> out, and a clear answer to why this is better than something that already exists." — the organisers
>
> Indistinguishable from what already exists: **0 out of 3.**

| File               | Holds                                                                        |
| ------------------ | ------------------------------------------------------------------------------ |
| `competitors.md`   | One entry per real product, with links and dates checked                      |
| `landscape.md`     | The shape of the space: where it is crowded, where the gap is, and why        |
| `deck-scan.md`     | 2026-09-06. Whether each page of the slide-deck mockup already exists          |
| `sources.md`       | Every product we have named, in one clickable list, marked read or unread     |

**The real competitor is usually not another app.** For a workload manager it is a group chat and a Notes app. For a
travel planner it is a spreadsheet and a WhatsApp group. Those belong in here too.

## What "Done" Looks Like

- **At least five products**, named, with links and the date checked
- At least one that makes our idea look unoriginal. **Finding it early is a good outcome** - it is much cheaper now than
  in the Q&A
- A written answer to "why does ours exist" that survives everything in the file
- Anything unverified marked `[not verified]`

Ask the `scout` agent to do the looking. It is set up for exactly this.
